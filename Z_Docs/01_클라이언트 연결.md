	- 서버, 클라이언트 추가 시도
		- 연결 풀 초과 시
			- [[ServerResponse#200 SystemMessage]]
				- Error, 연결 풀 초과
			- Dispose
2. 서버 -> 클라이언트, 이름과 UUID 요청
	- [[ServerRequest#301 UsernameRequest]]
	- 클라이언트에 저장된 이름이 있을 경우
		1. 클라이언트 -> 서버, 이름 전달
		2. 서버, 이름 확인
			- 이 이름으로 이미 접속이 되어있을 경우 
				- 서버 -> 클라이언트, 이름 재요청
					- [[ServerRequest#301 UsernameRequest]]
				- 사용자 이름 입력 순서로...
		1. 서버, 유저 목록에 해당 클라이언트 등록
		2. 서버 -> 클라이언트, UUID 전달, 방 목록 전달
			- [[ServerResponse#201 ApplyConnectionResponse]]
	- 없을 경우
		1. 클라이언트, 사용자의 이름 입력
		2. 클라이언트 -> 서버, 이름만 전송
		3. 서버, 이름 확인
			- 이름 중복 있을 경우
				- 서버 -> 클라이언트, 이름 재요청
					- [[ServerRequest#301 UsernameRequest]]
				- 사용자 이름 입력 순서로..
		4. 서버, 유저 목록에 해당 클라이언트 등록
		5. 서버 -> 클라이언트, UUID 전달, 방 목록 전달
			- [[ServerResponse#201 ApplyConnectionResponse]]
